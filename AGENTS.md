## Ecommerce software reviews

When writing or revising ecommerce software review pages, use the `$ecommerceintel-operator-review` skill.

Do not use this skill for standalone Pricing, Alternatives, Comparison, Tutorial, News, or Buying Guide pages. Use the dedicated page-type skill when available.

The review must use the relevant Tool-Type Adapter and must not invent test data, sales figures, ad duration, creator counts, revenue estimates, or live-use experience.
